최신 그래픽: 로고와 같은 각진 올리브 철판 화풍으로 캐릭터·바닥·이펙트·아이콘·패널을 통일했다. 게임 실행 화면에서 상태창과 결과창 배치를 확인했다. 걷기/이펙트는 4프레임 시트를 사용한다. 아래 기본 팩 설명 중 단일 프레임 설명은 기본·킥·날아가는 자세에 해당한다.

추가 업데이트: 걷기·타격·파괴·벽 충돌 애니메이션과 체력/킥 UI, 결과 패널까지 연결했다. 자세한 내용은 [추가 그래픽 적용 문서](../docs/추가그래픽_제작기록.md)를 참고한다. 아래 내용은 기본 리소스 팩의 설명이다.

# 고철 킥! 그래픽·효과음 팩

제작일: 2026-10-25

기존 기획의 파란 플레이어, 빨간 적, 주황색 피격 상태, 폐기장 전투장을 바탕으로 제작했다.

## 이미지

| 경로 | 크기 | 용도 |
| --- | --- | --- |
| image/player/player_idle.png | 64×64 | 플레이어 기본 자세 |
| image/player/player_kick.png | 64×64 | 오른쪽으로 발차기 |
| image/enemy/enemy_basic.png | 64×64 | 기본 적 |
| image/enemy/enemy_flying.png | 64×64 | 날아가는 적 |
| image/stage/arena_floor.png | 840×480 | 전투장 철판 바닥 |
| image/effect/kick_arc.png | 96×96 | 오른쪽으로 볼록한 노란 킥 궤적 |

바닥 이외의 PNG는 실제 알파 투명도를 포함한다. 작은 게임 화면에 사용할 수 있게 축소했으며, 별도 배포 묶음의 originals 폴더에 고해상도 원본을 보관했다. 캐릭터는 사선 위에서 본 아케이드 스타일이다. 8방향 애니메이션 시트가 아니라 각 상태별 단일 프레임이다.

## 사운드

모두 모노 PCM 16-bit, 44.1kHz WAV. 외부 녹음이나 샘플 없이 사인파·노이즈를 합성했다. 개별 피크는 약 -6.4dBFS로 맞췄다.

| 경로 (sound/sfx/) | 길이 | 재생 시점 |
| --- | --- | --- |
| kick_swing.wav | 0.18초 | 쿨다운을 통과한 킥 시작 |
| metal_hit.wav | 0.24초 | 킥 적중 또는 적끼리 충돌 |
| wall_hit.wav | 0.30초 | 날아가는 적의 벽 충돌 |
| player_hurt.wav | 0.32초 | 플레이어 체력 감소 |
| enemy_break.wav | 0.42초 | 적 제거 |
| clear.wav | 1.50초 | 클리어 전환 시 한 번 |
| game_over.wav | 1.50초 | 게임 오버 전환 시 한 번 |
| restart.wav | 0.18초 | 재시작 |

배경음악은 포함하지 않았다.

## 게임 코드 적용 완료

GameAssets.cs에서 이미지 18종과 효과음 8종을 초기화 때 한 번 로딩한다. GameMain.cs의 Render와 전투 이벤트에 연결했다. 기존 csproj 설정으로 실행·배포 폴더의 resource에 파일을 복사한다. 경로는 AppContext.BaseDirectory 기준이다.

- 바닥은 (30,90), 840×480에 출력한다. 플레이어는 50픽셀, 적은 48픽셀 크기로 투명 여백을 포함해 출력한다.
- 기본/킥/날아가는 자세를 상태에 맞게 바꾼다. 단일 방향 스프라이트를 방향 각도로 회전하는 방식이다. 8방향 별도 그림은 아니다.
- 킥 자세의 가로 중심을 보정하고, 공격 순간의 각도를 저장하여 킥 효과에 사용한다. 피격 무적 중에는 플레이어 투명도가 깜빡인다.
- 기존 화면 배율을 유지하며 로컬 회전을 합성하므로 창 크기 변경에도 좌표가 유지된다.
- 효과음은 실제 발차기, 적중, 벽 충돌, 플레이어 체력 감소, 적 제거, 클리어/게임 오버 전환, 재시작에 연결했다.
- 같은 음은 프레임당 한 번, 최소 0.06초 간격으로 재생한다. 재시작·창 비활성 시 소리를 정리하고 종료 시 자원을 해제한다.
- 오디오 장치가 없으면 소리 로딩을 건너뛴다. 효과음 전체 출력은 65%로 설정했다.

## 제작 정보

- 이미지: OpenAI 내장 image_gen으로 신규 생성. 사용자가 제공한 곱등이 로고를 화풍 참고로 사용했다. 기본 캐릭터 생성 결과를 자세 변형의 참조로 사용했다.
- 이미지 후처리: 알파를 유지한 크기 조절과 합본 프레임 분할을 수행했다. 고해상도 원본은 그대로 보관했다.
- 효과음: Codex가 작성한 C# 합성 코드를 PowerShell에서 실행하여 생성. 재생성 스크립트는 배포 묶음의 make_audio.ps1에 포함했다.
- 실제 이미지 생성 프롬프트는 배포 묶음의 PROMPTS.json에 보관했다.
- 외부 다운로드 리소스나 제3자 샘플의 라이선스를 이 파일들에 임의로 붙이지 않았다.

검증: PNG 크기와 실제 투명 픽셀, WAV 헤더·길이·피크 확인. 빌드 경고·오류 0개. 실제 Direct2D 텍스처 로딩과 두 배율에서 렌더링, 효과음 8개 재생 버퍼 제출, 킥·벽 충돌 이벤트, 재시작 초기화와 자원 해제 자동 검증 통과. 화면을 보며 수동으로 전체 게임을 플레이한 검증은 별도로 필요하다.
