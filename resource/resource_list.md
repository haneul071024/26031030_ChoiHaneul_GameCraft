# 고철 킥! 리소스 목록

- 이름: 최하늘
- 학번: 26031030

현재는 플레이어와 적을 원으로 그리고 있다. 기본 동작을 먼저 만든 상태라 이미지와 소리는 아직 넣지 않았다.
아래는 앞으로 사용할 리소스를 정리한 것이다. 파일명과 크기는 우선 이렇게 정하고, 실제로 적용하면서 조정할 예정이다.

이미지는 PNG로 준비한다. 바닥을 제외한 그림은 배경을 투명하게 만든다.
플레이어와 적은 원본을 64 × 64로 만들고 게임에서는 약 40 × 40으로 줄여서 사용할 생각이다.
현재 충돌 범위는 반지름 18이므로 그림의 몸체와 판정 범위가 너무 다르지 않게 맞춘다.
발차기 그림과 효과는 마지막으로 이동한 방향을 향하도록 출력해야 한다.

### 이미지가 없어도 되는 부분

- 게임 이름, 점수, 남은 적, 조작 설명은 지금처럼 글자로 표시한다.
- 게임 오버와 클리어 창은 사각형과 글자로 만든다.
- 피격 후 무적 상태는 밝은 색이나 깜빡임으로 표현한다.
- 전투장 테두리와 공격 방향선은 코드로 그린다.
- 적 위에 표시하는 체력 숫자는 그림에 넣지 않고 따로 출력한다.

## 사운드

현재는 소리가 없다. 우선 발차기와 충돌을 구분할 수 있는 효과음부터 넣을 예정이다.
효과음은 WAV, 배경음은 MP3로 준비한다.

| 이름 | 파일명 | 길이 | 재생할 때 |
| --- | --- | --- | --- |
| 발차기 소리 | kick_swing.wav | 0.1~0.25초 | J를 눌러 발차기가 나갈 때. 빗맞아도 재생한다. |
| 금속 타격음 | metal_hit.wav | 0.1~0.3초 | 적을 차거나 날아가는 적이 다른 적에게 부딪힐 때 |
| 벽 충돌음 | wall_hit.wav | 0.15~0.35초 | 날아가는 적이 벽에 부딪힐 때 |
| 플레이어 피격음 | player_hurt.wav | 0.15~0.4초 | 플레이어의 체력이 실제로 줄었을 때 |
| 적 파괴음 | enemy_break.wav | 0.2~0.5초 | 적을 처치했을 때 |
| 클리어 소리 | clear.wav | 1~2초 | 모든 적을 처치했을 때 한 번 |
| 게임 오버 소리 | game_over.wav | 1~2초 | 플레이어 체력이 0이 되었을 때 한 번 |
| 전투 배경음 | scrapyard_battle.mp3 | 30~60초 | 전투 중 반복 재생. 효과음 적용 후 추가한다. |
| 재시작 소리 | restart.wav | 0.1~0.2초 | 결과 화면에서 Enter를 눌렀을 때. 여유가 있으면 추가한다. |

### 소리 준비할 때 확인할 점

- 효과음은 가능하면 PCM 16-bit, 44.1 kHz WAV로 맞춘다.
- 소리 앞에 무음이 길면 반응이 늦게 느껴지므로 잘라낸다.
- 여러 적이 한꺼번에 맞아도 소리가 너무 커지지 않게 한다.
- 무적 상태에서 적과 닿았을 때는 피격음을 다시 재생하지 않는다.
- 클리어와 게임 오버 소리가 계속 반복되지 않게 한다.
- 배경음은 효과음보다 작게 하고, 반복되는 부분이 어색하지 않은지 들어 본다.
- 다시 시작할 때 이전 소리가 남거나 배경음이 겹치지 않는지 확인한다.

## 저장할 폴더

아직 아래 파일과 폴더를 모두 만든 것은 아니다. 준비한 파일은 다음 위치에 넣는다.

```text
resource/
├─ resource_list.md
├─ image/
│  ├─ player/     플레이어 기본 모습, 발차기, 걷기
│  ├─ enemy/      기본 적, 날아가는 적, 걷기
│  ├─ stage/      전투장 바닥
│  ├─ effect/     발차기, 타격, 파괴, 벽 충돌 효과
│  └─ ui/         체력 아이콘
├─ sound/
│  ├─ sfx/       효과음
│  └─ bgm/       배경음
└─ licenses/     내려받은 리소스의 이용 조건
```

파일을 넣은 뒤에는 실행 파일이 있는 폴더에서도 불러올 수 있도록 프로젝트 설정을 확인한다.

## 출처와 라이선스

아직 이미지와 사운드를 구하지 않아서 출처는 미정이다.
외부 파일을 사용하면 아래 표에 제작자와 다운로드 주소, 사용 조건을 적는다.
직접 만든 파일은 제작자를 적고, 수정한 파일은 수정 내용도 남긴다.

| 파일명 | 제작자 | 출처 주소 | 라이선스 / 사용 조건 | 수정 내용 |
| --- | --- | --- | --- | --- |
| 이미지·사운드 확보 후 작성 | 미정 | 미정 | 확인 후 작성 | 해당 시 작성 |

무료 파일이라도 이름을 표시해야 하거나 재배포가 제한될 수 있으므로 다운로드한 곳의 설명을 확인한다.
라이선스 문서가 함께 있으면 licenses 폴더에 보관한다.

### 현재 사용한 것

- glc2d: [교수님 GitHub 예시](https://github.com/3dapi/90018899_HeesungOh_GameCraft/tree/f1/src/glc2d)의 소스를 사용했다. 수정한 부분은 [glc2d 출처 문서](../docs/glc2d_출처.md)에 적었다.
- 글꼴: Windows에 설치된 맑은 고딕을 사용한다. 글꼴 파일을 따로 넣지는 않았다.
- 플레이어, 적, 배경: 현재는 GameMain.cs에서 도형으로 그린다.

## 준비 순서

1. 플레이어, 적, 바닥 등 기본 이미지 6개를 준비한다.
2. 게임에 넣어서 위치와 크기, 공격 방향이 맞는지 확인한다.
3. 발차기부터 게임 오버까지 기본 효과음 7개를 준비하고 적용한다.
4. 출처와 사용 조건을 기록한다.
5. 시간이 남으면 걷기 애니메이션, 타격 효과, 배경음을 추가한다.

처음 준비할 파일은 이미지 6개와 효과음 7개로 총 13개이다.
대시, 드럼통, 보스는 아직 게임에 없으므로 관련 리소스는 기능을 추가하기로 정한 뒤 준비한다.

## 적용 후 확인

- [ ] 플레이어와 적이 배경에서 잘 보이는지
- [ ] 그림의 위치와 실제 충돌 위치가 맞는지
- [ ] 발차기 방향과 효과 방향이 맞는지
- [ ] 소리가 맞는 상황에서 한 번씩 나오는지
- [ ] 여러 효과음이 겹칠 때 너무 시끄럽지 않은지
- [ ] 재시작하면 이전 효과와 소리가 정리되는지
- [ ] 창 모드와 전체 화면에서 잘리지 않는지
- [ ] Visual Studio 밖에서 실행해도 파일을 찾는지
- [ ] 사용한 파일의 출처를 빠짐없이 적었는지
