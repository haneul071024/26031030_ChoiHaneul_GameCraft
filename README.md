## 게임 소개

다가오는 로봇을 발로 차서 처치하는 2D 액션게임이다.
적을 다른 적이나 벽에 날려서 추가 피해를 줄 수 있다.
현재는 기본 동작을 구현한 버전으로, 이미지 대신 도형을 사용하고 있다.

## 실행 방법

1. Visual Studio 2022에서 `src/ActionGame/ActionGame.sln`을 연다.
2. .NET 9를 지원하는 Visual Studio와 `.NET 데스크톱 개발` 구성 요소가 필요하다.
3. 처음 실행할 때 NuGet 패키지를 복원한다. 인터넷 연결이 필요할 수 있다.
4. 시작 프로젝트를 `ActionGame`으로 선택하고 F5를 누른다.

glc2d는 교수님 예제의 소스를 프로젝트 안에 포함했다.
별도로 glc2dcsharp 패키지를 설치하지 않아도 된다.

## 조작

| 키 | 동작 |
| --- | --- |
| W / A / S / D | 이동 |
| J | 마지막으로 이동한 방향으로 발차기 |
| Enter | 결과 화면에서 다시 시작 |
| Alt + Enter | 전체 화면 전환 |

적 6마리를 모두 처치하면 클리어하고, 체력이 0이 되면 게임 오버이다.
발차기는 0.4초 간격으로 사용할 수 있으며, 키를 떼었다가 다시 눌러야 한다.
