## 게임 소개

다가오는 로봇을 발로 차서 처치하는 2D 액션게임이다.
적을 다른 적이나 벽에 날려서 추가 피해를 줄 수 있다.
로봇 이미지와 폐기장 바닥을 표시하고, 발차기·충돌·결과 화면에 효과음을 재생한다.

## 실행 방법

1. Visual Studio 2022에서 `src/ActionGame/ActionGame.sln`을 연다.
2. .NET 9를 지원하는 Visual Studio와 `.NET 데스크톱 개발` 구성 요소가 필요하다.
3. 처음 실행할 때 NuGet 패키지를 복원한다. 인터넷 연결이 필요할 수 있다.
4. 시작 프로젝트를 `ActionGame`으로 선택하고 F5를 누른다.

glc2d는 교수님 예제의 소스를 프로젝트 안에 포함했다.
별도로 glc2dcsharp 패키지를 설치하지 않아도 된다.

## 조작

| 키 | 동작 |
| --- | --- |
| W / A / S / D 또는 방향키 | 이동 |
| J | 마지막으로 이동한 방향으로 발차기 |
| Enter | 시작 / 다음 라운드 / 다시 도전 |
| Esc | 일시정지·재개 / 결과·정비에서 로비 |
| M | 배경음악 켜기·끄기 |
| L | 일시정지 메뉴에서 로비로 복귀 |
| Alt + Enter | 전체 화면 전환 |

로비에서 시작해 적 6 / 8 / 10대의 세 라운드를 모두 통과하면 클리어한다. 체력이 0이면 게임 오버이다. 2라운드부터 경고 후 작동하는 전기 바닥을 피하거나 적을 밀어 넣어 활용한다.
발차기는 0.4초 간격으로 사용할 수 있으며, 키를 떼었다가 다시 눌러야 한다.

## 4차 제출 준비

4차 주요 사항은 최소 한 게임 플레이 진행, 기획서 보강, 리소스 정리이다. [기획서](docs/기획서.md)에 로비부터 결과·재도전까지의 실제 조작 확인 절차와 라운드별 규칙을 정리했다. 직접 플레이 완료 여부는 아래 자동 검증과 구분한다.

2026-11-08 직접 이동·킥을 입력하여 수정 전 700점, 수정 후 500점으로 각각 패배 결과까지 진행했다. 수정 후 재도전·일시정지·전체 화면 비율도 확인했다. 3라운드 연속 승리는 자동 검증 범위이며 직접 달성하지 않았다. 자동 검증은 새 기능 4개를 포함해 32개 통과했다. 빌드 출력의 PNG 19개·WAV 9개 복사도 확인했다. NuGet 취약성 정보 조회에는 NU1900 경고가 발생했다.

플레이 점검 후 점수 팝업 겹침을 줄이고, 접촉 피격 시 32px 밀려남·공격 방향 표시·그림자·날아가는 적 잔상·피해 원인 표시·라운드별 팁을 추가했다. 결과 화면에서 처치 수·연쇄 횟수·전투 시간도 확인할 수 있다.

배경·캐릭터 렌더링, WASD/방향키 이동, 발차기·벽·연쇄 충돌, 로비, 3개 라운드, 실시간 점수, 라운드 시간/체력 보너스, 라운드 사이 체력 회복, 전기 바닥, 일시정지, 결과·재도전을 구현했다.

이미지 19종·효과음 8종·합성 BGM 1종을 역할별 resource 폴더에서 읽는다. 최고 점수는 현재 실행 동안 유지된다. M은 BGM만 제어한다. `tools/Make-Bgm.ps1`로 배경음악을 재생성할 수 있다.

## f3 제출 및 검증

- 3차 제출 버전은 Git 태그 `f3`로 구분한다. 소스, 프로젝트, 기획서와 이미지 19개·WAV 9개를 함께 제출한다.
- UI는 Windows 기본 한글 글꼴인 맑은 고딕을 사용한다. 별도 글꼴 설치가 필요하지 않다.
- 자동 검증 실행: `dotnet run --project tools/SmokeTests/SmokeTests.csproj`
- 2026-11-01 자동 검증 28개 통과: 리소스 로딩, 라운드 전환·승리·패배·재시작, 점수·회복, 전기 피해, 킥·쿨다운·벽·연쇄 충돌·무적, 점수 팝업, 화면 비율.
- 실제 창에서 로비, 라운드 시작, 일시정지·복귀, 패배, 재시작, 전체 화면의 비율과 글자 표시를 확인했다.
- 자동 검증은 상태와 전투 함수를 직접 호출한다. 직접 조작한 3라운드 연속 클리어, 학교 PC 실행, 실제 스피커 음량·음질은 별도 확인 대상이다.
- 검증 환경에서 NuGet 서버 연결 제한으로 `NU1900` 경고가 발생했다. 이는 취약성 정보 조회 실패이며, 취약성 검사가 완료되었다는 뜻은 아니다.
- `bin`·`obj`는 제출 대상에서 제외하며 빌드 시 생성한다. 소스에서 실행하려면 .NET 9 SDK와 패키지 복원이 필요하다.
