# 고철 킥! 실행 확인

확인일: 2026-10-18

실제 게임 실행 파일을 열고 화면 캡처와 키 입력으로 확인했다.

| 항목 | 결과 |
| --- | --- |
| 창 모드 화면 | 상단 정보, 전투장, 하단 설명, 결과 화면 전체 표시 확인 |
| 위 이동 | W 입력 후 플레이어의 위 이동 및 흰 방향선의 위쪽 전환 확인 |
| 킥 | J 입력 후 주황색으로 날아가는 적, 체력 감소 확인 |
| 연쇄 충돌 및 점수 | 킥 후 점수 750, 남은 적 1 표시 확인 |
| 패배 | 체력 0에서 게임 오버와 최종 점수 표시 확인 |
| 재시작 | Enter 후 체력 5, 점수 0, 적 6으로 초기화 확인 |
| 전체 화면 | Alt+Enter 전환 후 모든 화면 요소 표시 확인 |
| 창 모드 복귀 | Alt+Enter로 원래 크기 복귀 확인 |
| 빌드 | Debug 및 Release 빌드 오류 0, 경고 0 |

## 발견하여 수정한 문제

- Windows 고배율 환경에서 Direct2D가 중복 확대되어 오른쪽과 아래가 잘렸다.
  Direct2D를 96 DPI로 고정하고, 시작 창 크기는 모니터 DPI와 작업 영역을 반영했다.
- 매우 짧은 키 입력은 프레임별 키 상태 조회 사이에서 누락될 수 있었다.
  KeyDown 이벤트를 다음 입력 갱신까지 기록하여 킥과 재시작 입력이 반영되도록 보완했다.

## 추가로 확인할 것

모든 방향으로 오래 이동하기, J 길게 누르기, 벽 충돌만 따로 확인하기, 클리어까지 플레이하기는 아직 별도로 확인하지 못했다.
기획서에는 코드에 있는 규칙을 적었고, 위 표에는 실제 화면에서 확인한 내용만 적었다.
