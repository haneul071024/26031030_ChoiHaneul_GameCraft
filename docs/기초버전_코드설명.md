# 고철 킥! 코드 설명

## 실행 순서

Program의 Main에서 GameMain을 만들고 Run을 실행한다.
교수님 glc2d의 G2AppBase가 창을 만들고 아래 순서로 게임을 진행한다.

1. Initialize: 글꼴과 붓을 만들고 플레이어와 적을 배치한다.
2. Update: 입력을 확인하고 이동, 공격, 충돌, 체력과 점수를 처리한다.
3. Render: 현재 게임 상태를 화면에 그린다.

Initialize는 처음에 한 번 실행되고 Update와 Render는 계속 반복된다.
창을 닫으면 Dispose에서 사용한 글꼴, 붓과 장치를 정리한다.

## 파일별 역할

| 파일 | 역할 |
| --- | --- |
| Program.cs | 프로그램 시작 |
| GameGlobal.cs | 화면 크기와 게임 이름 |
| Player.cs | 플레이어 좌표, 체력, 속도, 공격 방향 |
| Enemy.cs | 적 좌표, 체력, 날아가는 속도 |
| GameMain.cs | 입력, 게임 규칙, 충돌과 화면 출력 |
| glc2d 폴더 | 교수님 예제의 프레임워크. 화면 크기와 입력을 일부 수정함 |

## 이동과 입력

WASD로 이동한다. IsKeyDown은 키를 처음 누른 순간이고 IsKeyPress는 계속 누르고 있는 상태이다.
이동에서는 두 상태를 모두 확인하고, 발차기는 처음 누른 순간만 확인한다.
짧게 눌렀다 떼는 입력도 놓치지 않도록 G2InputContext에서 KeyDown을 기록한다.

이동 거리는 `속도 × dt`로 구한다. dt는 직전 갱신 이후 지난 시간(초)이다.
속도가 240이고 dt가 0.016이면 3.84만큼 이동한다.
대각선 이동에서는 방향의 길이를 1로 맞춰 가로나 세로 이동과 속도가 같게 했다.

마지막으로 이동한 방향을 DirectionX와 DirectionY에 저장한다.
J를 누르면 그 방향으로 발차기한다. 창이 비활성 상태일 때는 진행을 멈춘다.

## 발차기와 충돌

Kick은 플레이어 앞쪽에 원 모양의 공격 범위를 만든다.
이 범위에 닿은 적은 체력이 1 줄고 LaunchEnemy에서 정한 속도로 날아간다.

- 적의 처음 체력은 2이다.
- 날아가는 적은 점차 느려지고 최대 0.65초 후 추적 상태로 돌아간다.
- 벽에 부딪히면 체력이 1 줄고 날아가는 상태가 끝난다.
- 다른 적에 부딪히면 상대의 체력이 1 줄고 상대도 날아간다.
- HitEnemies에 이미 맞힌 적을 기록하여 같은 상대에게 계속 피해를 주지 않게 한다.
- 적끼리 충돌하면 50점, 적을 처치하면 100점을 얻는다.

체력이 0인 적은 목록에서 제거한다. 목록을 뒤에서부터 확인하면 제거하면서 순서가 바뀌어도 다음 적을 건너뛰지 않는다.
플레이어는 적에게 맞으면 체력이 1 줄고, 이후 1초 동안 추가 피해를 받지 않는다.

## 화면 출력

Render에서는 그리기만 하고 좌표나 체력을 바꾸지 않는다.
도형은 RenderTarget, 글자는 G2Font.DrawText로 출력한다.

- Rgb: 0~255 색 값을 Direct2D가 사용하는 0~1 값으로 바꾼다.
- FillCircle: 중심 좌표와 반지름으로 원을 그린다.
- FillBox: 위치와 가로·세로 길이로 사각형을 그린다.
- DrawLabel: 기본 글꼴로 글자를 표시한다.

고배율 화면에서 그림이 잘리는 문제가 있어 Direct2D의 DPI를 96으로 맞췄다.
초기 창 크기는 모니터 배율을 반영하고, 화면의 작업 영역을 넘지 않게 조절한다.
게임 안의 좌표는 900 × 620을 기준으로 유지한다.

## 값을 바꿔 볼 곳

| 값 | 바뀌는 내용 |
| --- | --- |
| Player.Speed | 플레이어 이동 속도 |
| Player.Hp | 시작 체력. 상단 최대 체력 표시도 함께 수정해야 함 |
| Enemy.Hp | 적의 시작 체력 |
| Kick의 0.4f | 발차기 대기시간 |
| LaunchEnemy의 600 | 적이 날아가는 처음 속도 |
| StartGame의 좌표 | 적의 시작 위치 |

숫자 뒤의 f는 float 형식의 소수라는 뜻이다.
override는 부모 클래스의 함수를 게임에 맞게 구현할 때 사용한다.

## 리소스 추가

현재는 도형만 사용한다. 준비할 파일은 resource/resource_list.md에 정리했다.
프로젝트에는 resource 폴더의 파일을 실행 결과 폴더로 복사하는 설정을 추가했다.
이미지와 소리를 실제로 불러오는 코드는 파일을 준비한 뒤 작성해야 한다.
