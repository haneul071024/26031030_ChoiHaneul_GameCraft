# 고철 킥! 게임 기획서

- 게임: 고철 킥!
- 작성자: 최하늘
- 학번: 26031030
- 개발 환경: C#, .NET 9, glc2d, Visual Studio 2022
- 진행 상태: 기본 동작 구현, 이미지와 사운드는 준비 예정

## 개요

### 장르

2D 탑다운 액션게임. 위에서 내려다보는 전투장에서 로봇을 조작한다.

### 게임 소개

폐기장에 있는 로봇이 다가오는 적을 발로 차서 처치하는 게임이다.
플레이어는 적을 직접 공격하거나, 날아가는 적을 다른 적과 벽에 부딪히게 할 수 있다.
현재는 이미지 대신 도형을 사용하여 이동과 전투 규칙부터 구현한다.

### 재미 요소

- 적을 차면 빠르게 날아가므로 타격 결과를 바로 볼 수 있다.
- 적을 다른 적에게 날려 연쇄 충돌을 만들면 여러 적을 처치하고 추가 점수를 얻는다.
- 적들이 모이는 위치와 공격 방향을 생각하며 움직인다.
- 가까이 오는 적에게 맞기 전에 공격하고, 남은 체력을 관리한다.

## 게임 진행

1. 프로그램을 실행하면 전투를 바로 시작한다. 별도 타이틀 화면은 아직 없다.
2. 플레이어는 중앙에서 체력 5로 시작하고, 기본 적 6마리가 정해진 위치에 등장한다.
3. 적은 플레이어를 향해 이동한다. 플레이어는 이동과 킥으로 적을 처치한다.
4. 적을 전부 처치하면 클리어, 플레이어 체력이 0이면 게임 오버이다.
5. 결과 화면에는 최종 점수와 다시 시작 안내를 표시한다.
6. Enter를 누르면 체력, 점수, 적 배치와 공격 효과를 초기화하고 다시 시작한다.

### 전투 규칙

| 항목 | 현재 규칙 |
| --- | --- |
| 플레이어 체력 | 5, 적과 접촉하면 1 감소 |
| 피격 무적 | 피격 후 1초, 밝은 색으로 표시 |
| 이동 속도 | 초당 240, 대각선도 같은 속도 |
| 킥 방향 | 마지막으로 이동한 방향, 처음에는 오른쪽 |
| 킥 범위 | 플레이어 앞 42 위치에 있는 반지름 38의 원 |
| 킥 재사용 시간 | 0.4초, J를 떼었다가 다시 눌러야 함 |
| 적 체력 | 2 |
| 적 이동 속도 | 초당 65 |
| 직접 킥 | 적 체력 1 감소, 공격 방향으로 날아감 |
| 날아가는 상태 | 처음 속도 600, 점차 감속, 최대 0.65초 |
| 벽 충돌 | 날아가는 적 체력 1 감소, 날아가기 종료 |
| 적끼리 충돌 | 맞은 적 체력 1 감소, 같은 방향으로 날아감 |
| 중복 충돌 방지 | 한 번 날아가는 동안 이미 맞힌 상대를 기록 |
| 날아가는 적 | 플레이어에게 접촉 피해를 주지 않음 |
| 창 비활성 | 게임 진행을 잠시 멈추고 입력 기록 초기화 |

### 점수

- 적끼리 충돌 적중: 50점
- 적 처치: 100점
- 현재는 시간 보너스, 체력 보너스, 최고 점수 저장 기능이 없다.

## 조작

| 키 | 행동 |
| --- | --- |
| W / A / S / D | 위 / 왼쪽 / 아래 / 오른쪽 이동 |
| J | 마지막 이동 방향으로 킥 |
| Enter | 결과 화면에서 다시 시작 |
| Alt + Enter | 전체 화면과 창 모드 전환 |
| 창 닫기 | 게임 종료 |

마우스로 공격 방향을 조준하지 않는다. 이동 방향을 바꾼 뒤 J를 누른다.

## 플레이 Stage

### Stage 1: 폐기장 전투장

- 현재 스테이지는 1개이며 추가 웨이브는 없다.
- 게임 기준 화면은 900 × 620이다. 창 크기에 맞춰 출력 배율을 조절한다.
- 전투 영역은 왼쪽 위 (30, 90), 크기 840 × 480이다.
- 플레이어 시작 좌표는 (450, 320)이다.
- 적 시작 좌표는 (150, 180), (230, 180), (700, 180), (150, 470), (700, 470), (780, 470)이다.
- 플레이어와 적은 전투 영역 밖으로 나갈 수 없다.

### 화면 구성

- 상단: 게임 이름, 체력, 점수, 남은 적, 조작 안내
- 중앙: 전투장, 플레이어, 적, 킥 효과
- 하단: 색상 설명과 전체 화면 안내
- 종료 시 중앙: 클리어 또는 게임 오버, 최종 점수, 재시작 안내
- 파란 원: 플레이어 / 빨간 원: 적 / 주황 원: 날아가는 적
- 흰 선: 바라보는 방향 / 노란 원: 킥 판정의 짧은 시각 효과

## 주요 클래스

| 클래스 | 역할 | 주요 데이터 또는 함수 |
| --- | --- | --- |
| Program | 실행 시작 | Main, GameMain.Run 호출 |
| GameGlobal | 공통 설정 | ScreenSize, GameName |
| GameMain | 게임 진행과 출력 | Initialize, Update, Render, StartGame, Kick, CheckEnemyCollisions |
| Player | 플레이어 정보 | X, Y, Hp, Speed, DirectionX/Y, KickCooldown, InvincibleTime |
| Enemy | 적 정보 | X, Y, Hp, VelocityX/Y, FlyTime, HitEnemies |
| G2AppBase | glc2d 게임 반복과 장치 관리 | Run, DeltaTime, Input, RenderTarget |

GameMain이 Player 한 개와 Enemy 목록을 소유한다. 입력과 충돌은 GameMain에서 처리한다.
현재는 GameMain에서 전체 흐름을 확인할 수 있도록 구성했다.
