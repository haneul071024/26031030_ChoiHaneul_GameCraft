# 고철 킥! — 4차 기말 제출 기획서

- 작성자: 최하늘 / 학번: 26031030
- 환경: C#, .NET 9 Windows Forms, 교수님 glc2d, Direct2D / XAudio2
- 문서 갱신: 2026-11-08, 현재 코드 기준 3개 라운드의 2D 탑다운 액션게임

## 게임 소개와 목표

폐기장 로봇이 적을 발로 차서 작업장을 정리한다. 직접 킥뿐 아니라 벽 충돌과 적끼리의 연쇄 충돌로 여러 적을 처리하는 것이 핵심 재미다. 후반에는 주기적으로 켜지는 전기 바닥에 적을 밀어 넣어 위험을 공격 수단으로 활용한다. 체력 5 안에서 세 라운드를 통과하고 높은 누적 점수를 얻는 것이 목표다.

## 화면과 진행 흐름

로비 → 라운드 1 → 정비 화면 → 라운드 2 → 정비 화면 → 라운드 3 → 최종 결과.
체력이 0이면 현재 라운드에서 게임 오버로 전환된다. 마지막 적과 플레이어가 동시에 쓰러지면 패배를 우선한다.

- 로비: 로고, 세 라운드 소개, 조작법, 현재 실행 중 최고 점수, 음악 상태, Enter 시작 안내.
- 인게임 상단: 체력, 킥 쿨다운, 누적 점수, 남은 적. 전투장 안쪽 상단: 라운드 / 경과 시간 / 기믹 상태.
- 정비: 라운드 보너스와 누적 점수, 체력 1 회복(최대 5), 다음 기믹 설명. Enter로 다음 라운드를 시작한다.
- 결과: 성공/실패, 최종 점수. Enter로 새 게임, Esc로 로비.
- Esc 일시정지 중에는 전투·타이머·음악이 정지하며 Esc로 복귀한다. 다른 창으로 이동한 동안에도 진행과 소리가 멈춘다.

## 라운드 구성

| 라운드 | 이름 | 적 수 | 적 속도 | 기믹 |
| --- | --- | --- | --- | --- |
| 1 | 고철 정리 | 6 | 65 px/s | 벽 추가 피해, 연쇄 충돌 익히기 |
| 2 | 전력 누출 | 8 | 75 px/s | 중앙 세로 전기 바닥 |
| 3 | 과부하 | 10 | 85 px/s | 중앙 십자 전기 바닥 |

각 라운드 시작 시 플레이어는 안전한 (310, 320)에 배치된다. 적은 중심 (450, 330)의 타원 둘레에 배치된다. 체력과 점수는 라운드 사이 유지하고, 적·이펙트·쿨다운·라운드 타이머는 초기화한다.

## 전투와 전기 바닥 규칙

| 항목 | 규칙 |
| --- | --- |
| 이동 | WASD / 방향키, 240 px/s, 대각선 속도 정규화 |
| 킥 | J를 누른 순간, 재사용 0.4초, 마지막 이동 방향 |
| 킥 판정 | 플레이어 앞 42px 위치, 반지름 38px |
| 적 체력 | 2, 직접 킥 / 벽 충돌 / 연쇄 충돌 각각 피해 1 |
| 날아가기 | 초기 600 px/s, 감속, 최대 0.65초, 날아가는 적은 접촉 피해 없음 |
| 플레이어 피해 | 걷는 적 접촉 / 전기 바닥으로 1 감소, 1초 무적. 접촉 시 적 반대쪽으로 32px 밀려나며 경기장 안으로 제한 |
| 전기 주기 | 6초 반복: 0~2.5초 충전, 2.5~4초 노란 예고, 4~6초 파란 작동 |
| 전기 범위 | 세로 x=406~494, 3라운드는 가로 y=296~364도 추가 |
| 전기와 적 | 한 작동 주기 동안 적마다 피해 1, 교차점에서 중복 피해 없음 |

전기 판정에는 캐릭터 반지름을 포함한다. 적을 발로 차서 작동 영역 안에 넣거나, 적이 따라오도록 유도한 뒤 빠져나오는 전략이 가능하다.

## 점수 설계

- 적 처치: 100점 (전기로 처치한 경우 포함).
- 적끼리 연쇄 충돌: 적중당 50점.
- 라운드 완료: 기본 300 + 시간 보너스 max(0, 600 - 경과 정수 초 × 10) + 남은 체력 × 50.
- 보너스는 라운드 완료 시 한 번만 지급하고, 회복 전 체력으로 계산한다.
- 최고 점수는 이번 실행 동안 유지한다. 파일 저장 기능은 포함하지 않는다.

## 그래픽·사운드·리소스 관리

900×620 기준 화면, 전투 영역 (30, 90), 840×480. 폐기장 배경 이미지와 로봇 스프라이트를 렌더링한다. 걷기·타격·벽 충돌·파괴는 4프레임 시트를 사용하고, 방향에 맞게 회전한다. 피격 시 투명도가 깜빡인다. 로비는 실제 바닥·캐릭터·적·킥·타격 리소스로 움직이는 라운드 미리보기를 구성한다. 전기 바닥은 전용 4상태 타일 시트를 배치하고, 경고 테두리·방전 선·클리어 불꽃은 Direct2D 이펙트로 보강한다.

이미지 19개, 효과음 8개, 배경음악 1개를 역할별 폴더로 구분한다. BGM은 외부 샘플 없이 합성한 16초 / 120 BPM 루프이며 효과음과 별도 재생한다. M으로 끌 수 있고, 비활성·일시정지 시 중단하며 복귀하면 처음부터 다시 재생한다. 오디오 장치가 없을 때는 소리 없이 실행한다.

리소스 경로·제작 정보는 `resource/resource_list.md`에 정리한다. 실행 파일 기준 resource 폴더에서 한 번 로딩하고 종료 시 해제한다. 빌드·배포 시 자동 복사한다. BGM 재생성 도구는 `tools/Make-Bgm.ps1`이다.

## 4차 제출 대응과 플레이 확인 절차

4차 공지의 주요 사항은 최소 한 게임 플레이 진행, 기획서 보강, 리소스 정리이다. 현재 구현은 로비에서 시작하여 세 라운드를 통과하거나 체력 소진으로 결과 화면에 도달하는 한 게임 흐름을 제공한다. 보스, 대시, 저장형 최고 점수는 현재 범위에 포함하지 않는다.

1. 로비에서 Enter를 누르고 1.5초 준비 연출 후 이동·킥으로 첫 라운드의 적 6대를 처리한다.
2. 정비 화면에서 누적 점수·보너스·실제 회복량을 확인하고 Enter로 진행한다.
3. 2라운드는 세로 전기 바닥, 3라운드는 십자 전기 바닥을 피하거나 적에게 활용한다. 적 수와 이동 속도도 증가한다.
4. 세 라운드 완료 시 성공 결과와 최종 점수를 확인한다. 도중 체력이 0이면 실패 결과를 확인한다.
5. 결과에서 Enter로 체력·점수가 초기화된 새 게임을 시작하거나 Esc로 로비에 돌아간다.

2026-11-08 실제 키보드 입력으로 로비 → 전투 → 패배 결과까지 진행했다. 첫 판은 700점, 수정 후 판은 500점(처치 3대·연쇄 4회)이었다. 재도전, 일시정지와 전체 화면도 확인했다. 세 라운드 연속 승리는 직접 조작으로 확인하지 않았다. 자동 검증은 상태 전환과 전투 함수를 직접 호출하므로 직접 플레이와 구분한다. 라운드별 난이도 변화와 걷기·킥·피격·파괴·전기 애니메이션은 기존 과제의 콘텐츠 확장 및 동적 표현 항목에 대응한다.

## UI·학습 지원 후속 개선

각 라운드는 1.5초 작전 준비 후 시작한다. 준비 시간은 보너스 계산 시간에 포함하지 않는다. 전투 HUD에 처치 진행률, 전기 시작·종료까지 남은 시간, 점수 획득 위치의 짧은 팝업을 표시한다. 정비 화면에는 실제 회복량과 구역·시간·체력 보너스 내역을 표시한다. 일시정지에서 L로 도전을 종료하고 로비로 복귀할 수 있다.

공통 상수·라운드 이름·시간 보너스는 GameRules, 점수 글자의 수명은 ScorePopup이 담당한다. 게임 코드의 핵심 연산에 한국어 주석을 추가했고, 필기시험_공부노트.md에 함수 흐름과 계산 예제를 정리했다.

공격 방향 화살표는 쿨다운 상태에 따라 색이 바뀐다. 캐릭터 아래 그림자와 날아가는 적의 잔상으로 위치·속도를 표현한다. 피격 시 0.3초 동안 붉은 테두리와 피해 원인을 표시한다. 점수 팝업은 근처 글자와 간격을 벌리고 어두운 배경을 둔다. 결과 화면에는 총 처치 수·연쇄 횟수·전투 시간·마지막 피해 원인을 표시한다. 준비 화면에는 라운드별 공략 팁을 제공한다. 이 연출은 기존 리소스를 재사용한다.
