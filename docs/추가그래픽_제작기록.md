# 고철 킥! 추가 그래픽

기존 파란 플레이어·빨간 적의 디자인과 금속 질감을 유지한 추가 팩이다. OpenAI 내장 image_gen으로 제작했으며, 원본과 실제 프롬프트는 배포 ZIP의 originals와 PROMPTS.json에 포함했다. 후처리는 게임용 크기 변환 및 아이콘 사분면 분할만 수행했다.

## 동작과 이펙트

아래 PNG는 모두 **256×256, 2열×2행, 프레임당 128×128**이다. 프레임 순서는 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래이다. 기존 기획의 가로 4칸 시트와 다르므로 원본 사각형을 아래 규칙대로 선택한다.

`x = (frame % 2) * 128`, `y = (frame / 2) * 128` (정수 나눗셈)

| 파일 | 내용 | 권장 재생 |
| --- | --- | --- |
| player_walk_sheet.png | 파란 로봇의 걷기 포즈 4장 | 이동 중 8~10fps 반복 |
| enemy_walk_sheet.png | 빨간 적의 무거운 걸음 4장 | 추적 중 6~8fps 반복 |
| hit_spark_sheet.png | 접촉 섬광→불꽃→파편→잔불 | 적중 시 약 0.20초, 1회 |
| enemy_break_sheet.png | 붉은 장갑 파편·볼트·폭발·연기 | 처치 위치에서 약 0.40초, 1회 |
| wall_hit_sheet.png | 벽에서 안쪽으로 튀는 불꽃과 분진 | 벽 충돌 시 약 0.28초, 1회 |

걷기는 단일 오른쪽 방향의 4포즈이다. 별도 8방향 애니메이션은 아니다. 생성된 프레임 간 보폭·몸 중심에 작은 차이가 있으므로 실제 애니메이션에서 기준점 보정을 조정할 수 있다. 걷기 시트를 프레임 크기와 같은 128픽셀로 화면에 출력할 필요는 없으며, 기존 플레이어·적의 화면 크기에 맞춰 축소한다.

wall_hit_sheet의 불꽃은 왼쪽으로 퍼진다. 충돌점은 프레임 중앙이 아닌 **대략 (0.83, 0.50)**에 있으므로 이 점을 벽 접촉 위치에 맞춰 배치하고 벽 방향에 따라 회전한다. 완전한 정밀 앵커는 실제 플레이 화면에서 조정한다.

## 인터페이스

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| status_icons.png | 256×256 | 왼쪽 위 체력 있음, 오른쪽 위 체력 없음, 왼쪽 아래 킥 준비, 오른쪽 아래 킥 대기 |
| hp_full.png | 64×64 | 켜진 청록색 에너지 코어 |
| hp_empty.png | 64×64 | 꺼지고 금이 간 코어 |
| kick_ready.png | 64×64 | 금색 테두리의 킥 아이콘 |
| kick_cooldown.png | 64×64 | 회색 테두리의 대기 아이콘 |
| result_panel.png | 640×320 | 클리어·게임 오버 공용 철제 패널 |

아이콘 4개는 status_icons의 각 칸을 분리한 파일이다. 체력 코어 5개를 28~32픽셀 크기로 나열하고 남은 HP만 밝게 표시한다. 킥 아이콘은 쿨다운 상태에 따라 교체한다. 결과 패널의 제목·점수·Enter 안내는 그림에 포함하지 않았으며 G2Font로 별도 출력한다. 패널 내 텍스트 권장 영역은 x=64~576, y=55~265이다.

## 적용 완료

GameAssets.cs에서 걷기/이펙트 시트 5개, UI 아이콘 4개, 결과 패널을 추가 로딩한다. status_icons.png는 개별 아이콘과 내용이 같으므로 중복 로딩하지 않는다.

GameMain.cs에서 플레이어 실제 이동 중 9fps, 적 추적 중 7fps로 걷기를 재생한다. 킥·비행 상태는 기존 전용 자세를 우선한다. 멈추거나 게임이 끝나면 걷기를 멈춘다.

GameEffect.cs는 효과 위치와 재생 시간을 적과 별도로 관리한다. 타격 0.20초, 파괴 0.40초, 벽 충돌 0.28초로 4프레임을 한 번 재생한다. 벽 이펙트는 접촉점에 맞춰 회전한다. 마지막 적이 제거되거나 결과창이 떠도 효과는 종료까지 진행하며, 재시작 때 모두 지운다. 창 비활성 시 게임과 함께 일시 정지한다.

상단에 에너지 코어 5개와 킥 준비/대기 아이콘, 남은 대기 시간을 표시한다. 결과창은 철제 패널에 결과·점수·재시작 안내를 출력한다. 기존 사운드 이벤트 연결은 유지한다.

검증: 빌드 경고 0개·오류 0개. 이미지 16개 로딩, 추가 시트 20프레임과 플레이어 걷기·결과 패널의 실제 Direct2D 출력, 두 배율의 변환 복원, 효과 생성/프레임 진행/적 제거 후 유지/만료, 재시작 초기화, WAV 8개 재생 버퍼 제출 및 자원 해제를 자동 검증했다. 수동 전체 플레이와 시각적 애니메이션 품질 평가는 수행하지 않았다.
